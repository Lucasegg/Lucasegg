# Roadmap — Banco de Soluções

## Fase 0 — Fundação

- Definir visão do produto e escopo do MVP.
- Criar documentação de contribuição e arquitetura.
- Configurar React, TypeScript, Vite, Tailwind e GitHub Actions.

## Fase 1 — MVP navegável

- Landing page.
- Explorar soluções.
- Explorar problemas.
- Detalhes de solução e problema.
- Pesquisa e categorias.
- Formulários de cadastro com feedback local.
- Deploy estático no GitHub Pages.

## Fase 2 — Persistência e autenticação

- Criar projeto Supabase.
- Modelar tabelas de problemas, soluções, categorias e perfis.
- Implementar autenticação.
- Salvar cadastros no banco.
- Regras de segurança Row Level Security.

## Fase 3 — Colaboração

- Comentários.
- Favoritos.
- Votos de utilidade/impacto.
- Sugestões de melhoria.
- Relacionamento muitos-para-muitos entre problemas e soluções.

## Fase 4 — Curadoria e qualidade

- Moderação.
- Tags avançadas.
- Status editorial.
- Denúncias.
- Destaques e coleções.

## Fase 5 — Comunidade e escala

- Perfis públicos.
- Organizações.
- API pública.
- Internacionalização.
- Métricas públicas de impacto.
